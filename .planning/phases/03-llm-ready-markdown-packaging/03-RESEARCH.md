## Summary

Phase 3 is a **second renderer**, not a second analyzer. `analyze.Run` already produces a format-agnostic `Report`; executive Markdown and JSON stay unchanged. Ship `RenderLLM` that emits a paste-tuned Markdown packet with system-prompt framing, archive identity, ranked hints (citations + short excerpts), notes, an explicit secrets warning, and a distinct footer — then enforce a hard **byte budget** with head/tail truncation and visible omit markers.

Redaction today only rewrites `*.log` at collect time. LLM paste must not claim safety; keep excerpts short, prefer paths, and warn. Zero new module dependencies; no tiktoken; no `--format`; no `--budget-bytes` in v1.1.0 (constant-only).

**Primary recommendation:** Add `internal/analyze/render_llm.go` with `RenderLLM(Report) (string, error)`, `DefaultLLMBudgetBytes = 32 << 10`, omit marker `… [omitted %d bytes] …`, wire `--output llm` in `renderAnalyze`, and lock behavior with goldens + a size-ceiling test.

### Pattern 2: Priority shrink before head/tail

**What:** Fit under `DefaultLLMBudgetBytes` by dropping lowest-value content first, never silently.  
**When to use:** Every `RenderLLM` call.  
**Drop order (high → keep longest):**

1. System-prompt framing (never drop; if framing alone exceeds budget → error — should be impossible at ~1–2 KiB)
2. Secrets warning + footer (never drop)
3. Archive identity + disclaimer
4. Summary line
5. Notes / open questions (trim messages; keep codes/paths)
6. Hints: keep higher severity / earlier ranked; drop trailing hints last
7. Within a kept hint: shrink/remove excerpts (keep `path`) before dropping the hint title/summary
8. Last resort: head+tail the entire findings body with omit marker

### Anti-Patterns to Avoid

- **Second analyzer / re-`Run` inside RenderLLM:** Violates D-01; doubles I/O and drifts goldens.
- **Silent `s[:n]` truncation:** Models invent continuity; violates D-04 / PITFALLS.
- **tiktoken / model-specific counts:** Violates D-03; false precision across Claude/ChatGPT.
- **Claiming ChatGPT-safe paste:** Redaction is `.log`-only; violates D-07 / LLM-03.
- **Parallel `--format` flag:** Violates D-02.
- **Dumping full evidence members:** Violates LLM-02/03; Phase 2 already clipped excerpts.

## Common Pitfalls

### Pitfall 1: Silent truncation
**What goes wrong:** Paste hits context limits; model invents omitted middle.  
**Why it happens:** Easy `[:budget]` cut without markers.  
**How to avoid:** Always insert `… [omitted N bytes] …`; golden asserts marker when forced over budget.  
**Warning signs:** Ceiling test passes length but `omitted` absent.

### Pitfall 2: Secret amplification
**What goes wrong:** Excerpts from `.txt`/`.tsv`/events carry secrets into vendor LLM retention.  
**Why it happens:** Collect redaction only walks `*.log` `[VERIFIED: internal/collector/redact.go:41-43]` — quote: `if !strings.HasSuffix(strings.ToLower(d.Name()), ".log") { return nil }`.  
**How to avoid:** `llmExcerptMaxRunes=256`; prefer paths; mandatory secrets warning; no “safe for ChatGPT” docs.  
**Warning signs:** Goldens contain env-looking tokens; docs claim safety.

### Pitfall 3: Second analyzer
**What goes wrong:** LLM path re-parses archive / invents findings.  
**Why it happens:** Temptation to “enrich” paste with more logs.  
**How to avoid:** Pure `RenderLLM(Report)`; unit tests feed synthetic `Report` without tar.  
**Warning signs:** `RenderLLM` imports `arcread` or calls `Run`.

### Pitfall 4: Cutting framing/warning first
**What goes wrong:** Budget squeeze removes system prompt or secrets banner.  
**Why it happens:** Naive left-to-right truncate of full document.  
**How to avoid:** Priority shrink (Pattern 2); never drop framing/warning/footer.  
**Warning signs:** Truncated golden missing “may contain unredacted”.

### Pitfall 5: Exit code confusion
**What goes wrong:** Invalid `--output` mapped to exit 3.  
**Why it happens:** Wrapping all errors in `ExitCollectAborted`.  
**How to avoid:** Keep render errors as plain `error`; archive open failures only → exit 3 `[VERIFIED: internal/cmd/exitcode.go:25]` — quote: `ExitCollectAborted  = 3`.  
**Warning signs:** `TestAnalyze_InvalidOutputRejected` fails.

### Omit helper (rune-safe head/tail)

```go
// Source pattern: ecosystem head/tail + visible marker [CITED: tool-output / observation-budget guides]
func headTailOmit(s string, maxBytes int) string {
	if maxBytes <= 0 || len(s) <= maxBytes {
		return s
	}
	marker := fmt.Sprintf(llmOmitMarkerFmt, len(s)-maxBytes) // N = omitted payload bytes (document)
	// Split remaining budget between head and tail after marker length;
	// cut on rune boundaries (utf8.DecodeRuneInString / DecodeLastRuneInString).
	// Prefer ~50/50 or 60/40 head/tail; cut at '\n' when within 20% of cut point.
	return head + marker + tail
}
```

**Marker format (lock):** `… [omitted %d bytes] …`  
Example: `… [omitted 4096 bytes] …`  
Tests may match substring `[omitted` and `bytes]`.
