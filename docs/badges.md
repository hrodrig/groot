# README badge reference

This page explains the badges shown at the top of the [project README](../README.md#readme-top).

- **release** — latest [GitHub *Release*](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases) (published notes and assets).
- **version** — latest **git tag** on the repo. **release** and **version** can differ if a tag was pushed without publishing a Release yet; install artifacts are still on the [tags](https://github.com/hrodrig/groot/tags) / release page for that tag.
- **`VERSION` file** — in the default branch, the [`VERSION`](../VERSION) file is the source of truth for the next release number.
- **Codecov** — merged test coverage from the CI upload on **`main`** (see [Codecov](https://codecov.io/gh/hrodrig/groot)).
- **dev.to** — companion walkthrough on [DEV Community](https://dev.to/).
- **Ask DeepWiki** — [DeepWiki](https://deepwiki.com/hrodrig/groot/) documentation index for this repository.
