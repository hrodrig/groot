<domain>
## Phase Boundary

Ship an **LLM-ready Markdown** renderer over the **same** Phase 2 `analyze.Report` — budgeted paste pack with system-prompt framing, ranked findings, head/tail truncation with **visible omit markers**, and an explicit secrets warning. No second analyzer, no in-process LLM API, no tiktoken, no `#56` diff, no full `#45` redaction engine. Default executive Markdown (`--output text`) and JSON remain unchanged.

<decisions>
## Implementation Decisions

### Package / API
- **D-01:** Add `RenderLLM(Report) (string, error)` (name discretionary) in `internal/analyze` beside `RenderExecutive`. Pure function over `Report` — no re-scan of archive inside the LLM renderer. — **Reversibility:** reversible
- **D-02:** CLI extends existing flag: `--output text|json|llm` (default stays `text`). Reject inventing a parallel `--format`. Invalid values error clearly (non-3 unless archive open failed).

### Budget / truncation
- **D-03:** Soft **byte/rune budget** only (no tiktoken / model-specific tokenizer). Default hard ceiling in the ~24–48 KiB range (exact number = Claude discretion; document constant). Enforce at render time; never dump unbounded log bodies.
- **D-04:** Truncation strategy: **head + tail** with a visible omit marker (e.g. `… [omitted N bytes] …`). Silent truncation forbidden. Prefer dropping lower-severity / later hints and shrinking excerpts before cutting framing/header/warning.
- **D-05:** Excerpt defaults stay aggressive (reuse Phase 2 evidence caps / clip further for LLM pack if needed). Prefer path citations over raw log paste.

### Framing / secrets
- **D-06:** LLM Markdown structure (stable order for goldens): (1) system-prompt / instruction block for the paste consumer, (2) archive identity (`run_id` / `archive_sha256` when present), (3) hint/hypothesis disclaimer, (4) ranked findings with citations + bounded excerpts, (5) notes / open questions, (6) **secrets warning** that paste may still contain unredacted archive text, (7) footer `generated by groot analyze --output llm`.
- **D-07:** Do **not** implement full `#45` redaction extensions in this phase. Satisfy LLM-03 via short citations + warning. Track `#45` as follow-up before richer snippets. No claim of “ChatGPT-safe” paste.

### Out of scope
- **D-08:** No MCP, no LLM API calls, no second heuristic engine, no layout bump, no committed `testing/fixtures/archives/` corpus (Phase 4). Tiny unit testdata / goldens under `internal/analyze/` OK.

### Claude's Discretion
- Exact budget constant, omit-marker wording, system-prompt text (English, evidence-first, no root-cause claims).
- Whether budget flag `--budget-bytes` ships in v1.1.0 or constant-only (prefer constant-only unless trivial).
- Template via `text/template` vs builders — prefer `text/template` + `missingkey=error` mirroring executive.

</decisions>
