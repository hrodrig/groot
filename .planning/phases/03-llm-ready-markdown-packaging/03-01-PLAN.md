## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator → `groot analyze` CLI | Local archive path and `--output` flag; untrusted archive bytes already constrained by arcread |
| `analyze.Report` → `RenderLLM` | Structured findings/excerpts become paste text for an external LLM (out of process) |
| Paste packet → external LLM vendor | Operator-controlled disclosure; groot does not call the vendor |
